# Mingwei Zhang — Software & Game Developer

Personal portfolio showcasing gameplay development, software projects, and interactive work.

**Live portfolio:** https://mingwzhang.github.io/portfolio/  
**GitHub:** https://github.com/mingwzhang

## Highlights

- Featured games with gameplay previews, project summaries, and links to their releases
- Interactive target mini-game built into the portfolio
- 2D and 3D asset galleries with keyboard-accessible browsing
- Skills, education, and contact information
- Responsive layout with an original retro arcade presentation

## Technologies

React, JavaScript, CSS, and supporting front-end libraries. The project is developed with the Create React App toolchain and published using GitHub Pages.

## Source layout

- `src/App.js` — page composition and section state
- `src/components/` — navigation, effects, and shared UI
- `src/sections/` — portfolio content and interactive features
- `src/data/` — technology and skills data
- `src/styles/` — global layout, typography, and responsive styling
- `public/video/` — gameplay previews and thumbnails
- `public/img/` — portraits, logos, and art assets
